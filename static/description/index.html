AIRIV Indonesia Payment Gateway Rail

Indonesia Tri-Gateway Payment Acquirers

Unified Odoo 18 payment provider layer for Indonesian domestic rails and cross-border settlement through Midtrans, Xendit, and PayPal with webhook-driven transaction state updates.

Odoo 18 CommunityMidtransXenditPayPalAIRIV

Core Capabilities

AIRIV Payment Indonesia adds Indonesian payment-provider configuration, QRIS and virtual-account flags, gateway references, and direct webhook endpoints for common domestic and international checkout flows.

Provider Rail

Midtrans, Xendit, PayPal

Register Indonesian payment providers in Odoo payment configuration with merchant credentials, public/secret keys, and sandbox or production mode.

Channel Control

QRIS and virtual accounts

Enable Dynamic QRIS and virtual-account capabilities and store payment channel evidence on Odoo payment transactions.

Webhook Sync

Direct status callback routes

Receive Midtrans, Xendit, and PayPal webhooks directly in Odoo and map gateway statuses into transaction done, pending, or canceled states.

Feature & Workflow Automation

1

Install provider layer

Install the module after Odoo Payment and Accounting are available in the database.

2

Configure credentials

Open payment provider configuration and fill merchant ID, client/public key, server/secret key, environment, QRIS, and virtual-account settings.

3

Register webhooks

Point gateway dashboards to the Odoo callback URLs for Midtrans, Xendit, and PayPal.

4

Reconcile payments

Let webhook notifications update Odoo payment transactions and preserve gateway reference and channel evidence.

Installation Guidance

Install

Add to Odoo addons

Clone branch 18.0, add the module folder to your addons path, restart Odoo, update the apps list, and install the module.

Configure

Create payment providers

Fill gateway credentials, choose sandbox or production mode, and enable QRIS or virtual-account channels where applicable.

Operate

Connect callbacks

Register webhook URLs in each gateway dashboard and monitor transaction status updates in Odoo.

Configuration Checklist

DependenciesConfirm Odoo Payment and Accounting are installed.
Gateway accountsPrepare active Midtrans, Xendit, or PayPal Business account credentials.
EnvironmentStart in sandbox/testing mode before production activation.
Webhook URLsRegister Midtrans, Xendit, and PayPal callback URLs on the gateway side.
Transaction reviewConfirm payment transactions move to done, pending, or canceled based on gateway notifications.
